## 1. 프로젝트 개요

### 1.1 목적
9급 공무원 영어 시험을 준비하는 수험생을 위한 학습 플랫폼.
국어 과목 학습 페이지와 동일한 기반 구조 위에, **영어 과목의 특수성**을 반영한 추가 페이지·기능을 구축한다.

### 1.2 영어 과목의 특수성 (다른 과목과 차별화)

| 특성 | 의미 | 페이지 반영 |
|------|------|----------|
| 어휘 암기 | 단순 단어 외우기 → 문맥 추론 어휘 | `/vocabulary` 페이지 |
| 문법 패턴 | 한국어 문법 ≠ 영어 문법 (구조 자체가 다름) | `/grammar-patterns` 페이지 |
| 관용구 | 직역 불가능한 표현 다수 | `/idioms` 페이지 |
| 실무 영어 | 2025년부터 공무원 직무 영어 출제 | `/business-english` 페이지 |
| 공통 지문 묶음 | 2025년 신유형 (1지문 2문제) | `/passage-bundle` 페이지 |
| 시각 자료 | 메신저·이메일·웹페이지 UI 그대로 출제 | UI 컴포넌트 재현 |
| 영문 지문 보존 | 한국어 번역 X, 원문 학습 | 모든 페이지 영문 우선 |

### 1.3 목표 사용자 시나리오

- **수험생 A**: 시험까지 3개월 남음 → 매일 어휘 30개 + 문법 패턴 1개 학습
- **수험생 B**: 모의고사 후 약점 보완 → 틀린 문제 영역별 자동 복습
- **수험생 C**: 시험 1주 전 → 빈출 TOP 10 + 함정 TOP 15 집중 학습

### 2.3 요약노트_JSON.json 구조 (반드시 참고)
최상위 12개 키:
- `exam_info` - 시험 기본 정보
- `paradigm_shift_2025` - 2025년 패러다임 전환 (dead_zones / power_zones)
- `predicted_distribution_2026_local` - 2026 지방직 영역 분포 예측
- `top_10_frequent_areas` - 빈출 영역 TOP 10
- `vocabulary_essentials` ⭐ - 시사 어휘 50선 (5분야)
- `grammar_patterns` ⭐ - 핵심 문법 패턴 10개
- `idioms_and_phrases` ⭐ - 관용구 4분야
- `business_english` ⭐ - 실무 영어 5분야
- `top_15_traps` - 함정 TOP 15
- `time_allocation_strategy` - 시간 배분 전략
- `exam_day_checklist` - 시험 직전 체크리스트
- `winning_mindset` - 합격 마인드셋 3가지

## 3. 기술 스택 권장사항

### 3.1 권장 스택
- **Frontend**: Next.js 15 (App Router) + TypeScript + Tailwind CSS
- **Backend**: Next.js API Routes (또는 별도 백엔드)
- **Database**: Supabase (PostgreSQL) - 인증·실시간·스토리지 통합
- **상태관리**: Zustand 또는 React Context
- **UI 컴포넌트**: shadcn/ui (또는 Radix UI + Tailwind)
- **PDF 뷰어**: react-pdf (요약 노트 PDF 뷰어용)
- **마크다운 렌더**: react-markdown + remark-gfm (표 지원)

### 3.2 영어 학습에 필요한 추가 패키지
- **`lucide-react`**: 아이콘 (책, 펜, 시계 등)
- **`framer-motion`**: 카드 플립 애니메이션 (어휘 학습)
- **`recharts`**: 학습 진도 시각화
- **`react-hot-toast`**: 정답/오답 피드백 토스트
- **선택**: `react-speech-kit` 또는 Web Speech API (어휘 발음 듣기)

## 4. 영어 특화 DB 스키마

### 4.1 공통 테이블 (다른 과목과 공유, 이미 존재할 가능성 높음)

```sql
-- 시험 정보
CREATE TABLE exams (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  year INT NOT NULL,
  month INT NOT NULL,
  day INT,
  subject VARCHAR(50) NOT NULL,        -- '영어'
  grade VARCHAR(20),                    -- '9급'
  region VARCHAR(50),                   -- '지방직'
  source_file TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 문제
CREATE TABLE questions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  exam_id UUID REFERENCES exams(id) ON DELETE CASCADE,
  number INT NOT NULL,                  -- 문제 번호 (1~20)
  question_text TEXT NOT NULL,
  explanation TEXT,
  area VARCHAR(50),                     -- '어휘빈칸', '어법밑줄', '공통지문' 등
  difficulty VARCHAR(20),               -- 'easy', 'medium', 'hard'
  has_visual BOOLEAN DEFAULT FALSE,     -- 시각 자료 포함 여부
  visual_type VARCHAR(30),              -- 'messenger', 'email', 'webpage', 'poster' 등
  bundle_id UUID,                       -- 공통 지문 묶음 ID (없으면 NULL)
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 선지
CREATE TABLE choices (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  question_id UUID REFERENCES questions(id) ON DELETE CASCADE,
  number INT NOT NULL,                  -- 1~4
  text TEXT NOT NULL,
  is_correct BOOLEAN DEFAULT FALSE,
  UNIQUE(question_id, number)
);

-- 사용자 시도 기록
CREATE TABLE user_attempts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL,
  question_id UUID REFERENCES questions(id),
  selected_choice_number INT,
  is_correct BOOLEAN,
  time_spent_seconds INT,
  attempted_at TIMESTAMPTZ DEFAULT NOW()
);

-- 북마크
CREATE TABLE bookmarks (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL,
  question_id UUID REFERENCES questions(id),
  note TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(user_id, question_id)
);
```

### 4.2 영어 특화 테이블 (신규 추가)

#### ① 어휘 (vocabulary)
```sql
CREATE TABLE vocab_words (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  word VARCHAR(100) NOT NULL,
  meaning_ko TEXT NOT NULL,
  meaning_en TEXT,                      -- 영영 정의 (선택)
  category VARCHAR(50) NOT NULL,        -- 'environment_climate', 'ai_digital' 등
  difficulty INT DEFAULT 1,             -- 1~5 (5가 가장 어려움)
  example_sentence TEXT,
  example_translation TEXT,
  exam_appeared_in TEXT,                -- '2025 지방직 1번' 같은 정보
  synonym TEXT[],                       -- ['mitigate', 'alleviate']
  antonym TEXT[],
  pronunciation TEXT,                   -- IPA 발음
  audio_url TEXT,                       -- TTS 또는 녹음 파일 URL
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_vocab_category ON vocab_words(category);
CREATE INDEX idx_vocab_word ON vocab_words(word);
```

#### ② 어휘 학습 진도 (vocab_progress)
```sql
CREATE TABLE vocab_progress (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL,
  vocab_id UUID REFERENCES vocab_words(id),
  status VARCHAR(20) DEFAULT 'new',     -- 'new', 'learning', 'reviewed', 'mastered'
  correct_count INT DEFAULT 0,          -- 정답 누적
  wrong_count INT DEFAULT 0,            -- 오답 누적
  last_reviewed_at TIMESTAMPTZ,
  next_review_at TIMESTAMPTZ,           -- 간격 반복 학습 (Spaced Repetition)
  mastery_level INT DEFAULT 0,          -- 0~5 (간격 반복 단계)
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(user_id, vocab_id)
);

CREATE INDEX idx_vocab_progress_user ON vocab_progress(user_id);
CREATE INDEX idx_vocab_progress_review ON vocab_progress(next_review_at);
```

#### ③ 문법 패턴 (grammar_patterns)
```sql
CREATE TABLE grammar_patterns (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  pattern_number INT,                   -- 1~10
  name VARCHAR(200) NOT NULL,           -- '가정법 과거완료 + 도치'
  form TEXT,                            -- 'Had + S + p.p., S + would have p.p.'
  korean_meaning TEXT,
  example_sentence TEXT,
  example_translation TEXT,
  equivalent_form TEXT,                 -- 'If S had p.p., ~'
  key_point TEXT,                       -- 풀이 포인트
  exam_appeared_in TEXT,                -- '2022 지방직 6번'
  related_verbs TEXT[],                 -- ['recommend', 'suggest', ...]
  difficulty INT DEFAULT 1,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

#### ④ 문법 패턴 학습 (grammar_pattern_views)
```sql
CREATE TABLE grammar_pattern_views (

  understood BOOLEAN DEFAULT FALSE,     -- 사용자가 '이해함' 체크
  last_viewed_at TIMESTAMPTZ DEFAULT NOW(),
```


### 5.2 영어 특화 페이지 상세

#### 🔠 `/vocabulary` - 어휘 학습 페이지

**목적**: 시사 빈출 어휘 50선을 분야별로 학습. 간격 반복 학습(Spaced Repetition) 알고리즘 적용.

**레이아웃**:
```
┌─────────────────────────────────────┐
│  상단 진도 바: 환경 7/10, AI 5/10 등    │
├─────────────────────────────────────┤
│  분야 탭: [환경] [AI] [행정] [보건] [경제] │
├─────────────────────────────────────┤
│   ┌────────────────────────┐         │
│   │   카드 (Flip 애니메이션) │         │
│   │                        │         │
│   │   앞면: mitigate        │         │
│   │  /ˈmɪtɪɡeɪt/  🔊       │         │
│   │                        │         │
│   │   클릭 → 뒷면         │         │
│   │   뒷면: 완화하다       │         │
│   │   예: We must mitigate │         │
│   │   the risks of AI.    │         │
│   │   [기출: 2026 국가직 1번] │         │
│   └────────────────────────┘         │
│                                     │
│   [😞 어려움] [🤔 보통] [😊 쉬움]      │
│   ← 이전        다음 →                │
└─────────────────────────────────────┘
```

**핵심 기능**:
- 카드 플립 (Framer Motion)
- TTS 발음 듣기 (Web Speech API)
- 어려움/보통/쉬움 평가 → `vocab_progress.mastery_level` 업데이트
- 간격 반복 알고리즘: SuperMemo SM-2 단순화
  ```
  쉬움: next_review = now + 7일, mastery +1
  보통: next_review = now + 3일, mastery 유지
  어려움: next_review = now + 1일, mastery -1
  ```
- 분야 필터, 검색
- "오늘의 복습 단어" 자동 큐 (next_review_at <= NOW())

**API 엔드포인트**:
```
GET  /api/vocabulary?category=ai_digital&status=learning
POST /api/vocabulary/review  { vocab_id, difficulty: 'easy'|'medium'|'hard' }
GET  /api/vocabulary/today   # 오늘 복습할 단어 목록
```

#### 📐 `/grammar-patterns` - 문법 패턴 페이지

**목적**: 9급 영어 핵심 문법 패턴 10개를 깊이 학습.

**레이아웃**:
```
┌─────────────────────────────────────┐
│  ← 문법 패턴 목록                     │
├─────────────────────────────────────┤
│  패턴 1. 가정법 과거완료 + 도치        │
│  ⭐⭐⭐⭐☆ (난이도)                  │
├─────────────────────────────────────┤
│  📐 형태                            │
│  Had + S + p.p., S + would/could    │
│  + have + p.p.                      │
│                                     │
│  📝 예시                             │
│  Had I realized what you were      │
│  intending to do, I would have      │
│  stopped you.                       │
│  → 내가 알아챘다면 막았을 텐데.        │
│                                     │
│  🔄 동등 표현                        │
│  = If I had realized what you ~     │
│                                     │
```

### 6.2 적재 스크립트 예시 (Node.js + Supabase)

```typescript
// scripts/seed-exams.ts
import { createClient } from '@supabase/supabase-js'
import set1 from '../data/exams/set1.json'
import set2 from '../data/exams/set2.json'
import set3 from '../data/exams/set3.json'

const supabase = createClient(process.env.SUPABASE_URL!, process.env.SUPABASE_SERVICE_KEY!)

async function seedExam(examData: any) {
  // 1. 시험 정보 적재
  const { data: exam, error } = await supabase
    .from('exams')
    .insert({
      year: examData.exam.year,
      month: examData.exam.month,
      day: examData.exam.day,
      subject: examData.exam.subject,
      grade: examData.exam.grade,
      region: examData.exam.region,
      source_file: examData.exam.source_file
    })
    .select()
    .single()
  
  if (error) throw error
  
  // 2. 문제와 선지 적재
  for (const q of examData.questions) {
    const area = inferArea(q.number)  // 문제 번호로 영역 추론
    const visualType = detectVisualType(q.question_text)
    
    const { data: question } = await supabase
      .from('questions')
      .insert({
        exam_id: exam.id,
        number: q.number,
        question_text: q.question_text,
        explanation: q.explanation,
        area,
        has_visual: !!visualType,
        visual_type: visualType
      })
      .select()
      .single()
    
    // 선지 적재
    for (const choice of q.choices) {
      await supabase.from('choices').insert({
        question_id: question.id,
        number: choice.number,
        text: choice.text,
        is_correct: choice.is_correct
      })
    }
  }
}

function inferArea(num: number): string {
  if ([1, 2].includes(num)) return '어휘빈칸'
  if (num === 3) return '어법빈칸'
  if ([4, 5].includes(num)) return '생활영어'
  if ([6, 7].includes(num)) return '공통지문1'
  if ([8, 9].includes(num)) return '공통지문2'
  if (num === 10) return '이메일목적'
  if ([11, 12].includes(num)) return '안내문일치'
  if ([13, 14].includes(num)) return '어법밑줄'
  if (num === 15) return '주제제목'
  if (num === 16) return '문장삽입'
  if (num === 17) return '어색한문장'
  if (num === 18) return '글의순서'
  if ([19, 20].includes(num)) return '긴지문빈칸'
  return '기타'
}

function detectVisualType(text: string): string | null {
  if (text.includes('[메신저')) return 'messenger'
  if (text.includes('[이메일')) return 'email'
  if (text.includes('[웹페이지')) return 'webpage'
  if (text.includes('[안내문')) return 'poster'
  return null
}

// 실행
await seedExam(set1)
await seedExam(set2)
await seedExam(set3)
```

### 8.1 어휘 간격 반복 학습 알고리즘 (SuperMemo SM-2 단순화)

```typescript
// lib/spacedRepetition.ts
type Difficulty = 'easy' | 'medium' | 'hard'

export function calculateNextReview(
  currentMastery: number,
  difficulty: Difficulty
): { nextReviewAt: Date; newMastery: number; status: string } {
  const now = new Date()
  let daysToAdd: number
  let newMastery: number
  let status: string
  
  switch (difficulty) {
    case 'easy':
      // 쉬움: 마스터리 +1, 간격 길어짐
      newMastery = Math.min(5, currentMastery + 1)
      daysToAdd = [1, 3, 7, 14, 30, 60][newMastery]
      status = newMastery >= 4 ? 'mastered' : 'reviewed'
      break
    case 'medium':
      // 보통: 마스터리 유지, 짧은 간격
      newMastery = currentMastery
      daysToAdd = [1, 2, 4, 7, 14, 30][newMastery]
      status = 'learning'
      break
    case 'hard':
      // 어려움: 마스터리 -1, 다음날 다시
      newMastery = Math.max(0, currentMastery - 1)
      daysToAdd = 1
      status = 'learning'
      break
  }
  
  const nextReviewAt = new Date(now.getTime() + daysToAdd * 24 * 60 * 60 * 1000)
  return { nextReviewAt, newMastery, status }
}
```

```typescript
      question:questions(area)
    `)
    .eq('user_id', userId)
  
  const areaStats: Record<string, { correct: number; total: number }> = {}
  for (const attempt of data || []) {
    const area = attempt.question.area
    if (!areaStats[area]) areaStats[area] = { correct: 0, total: 0 }
    areaStats[area].total++
    if (attempt.is_correct) areaStats[area].correct++
  }
  
  // 정답률 60% 미만 영역 = 약점
  const weakAreas = Object.entries(areaStats)
    .map(([area, stats]) => ({
      area,
      accuracy: stats.correct / stats.total,
      total: stats.total
    }))
    .filter(s => s.accuracy < 0.6 && s.total >= 3)
    .sort((a, b) => a.accuracy - b.accuracy)
  
  return weakAreas
}
```

## 10. 영어 특화 주의사항

### 10.1 영문 지문 보존 원칙
- ❗ **영문 지문은 절대 한국어로 번역하지 않는다**
- ❗ 해설에만 한국어 번역 포함
- ❗ 어휘 뜻은 한국어로 표시하되, 예문은 영문 그대로

### 10.2 어법 문제 렌더링
- 어법 밑줄 문제는 `①②③④` 번호와 함께 단어/구문에 명확한 시각적 강조
- 가능하면 클릭 가능한 인터랙티브 요소

```html
<!-- 권장 렌더링 -->
<p>
  The library, 
  <span class="grammar-option" data-num="1">①<u>which</u></span> 
  was once considered the greatest, 
  <span class="grammar-option" data-num="2">②<u>housed</u></span> 
  millions of scrolls...
</p>
```

### 10.3 공통 지문 묶음 (신유형) 처리
- 한 지문에 2문제가 연결됨 → DB 적재 시 `bundle_id`로 그룹핑
- 시험 풀이 UI에서 2문제를 한 번에 표시
- "이 묶음 모두 풀기" / "한 문제씩 풀기" 옵션 제공

### 10.4 TTS (Text-to-Speech) 처리
- 어휘 발음 듣기: Web Speech API 사용 (무료, 별도 키 불필요)
- 영어 발음: `utterance.lang = 'en-US'`
- 미국식/영국식 옵션 제공 시: `'en-US'` vs `'en-GB'`

### 10.5 검색 기능 - 영어 특화
- 어휘 검색: 영문 단어 + 한국어 뜻 모두 검색 가능
- 자동 완성: 영문은 prefix 매칭, 한국어는 부분 매칭
- 검색 결과: 어휘/문법/관용구/실무영어 통합 표시

### 10.6 성능 최적화
- 어휘 데이터는 클라이언트에 캐싱 (50개 정도면 메모리 부담 X)
- 시험 풀이 페이지는 SSR + 클라이언트 진행 상태 관리
- PDF 뷰어는 lazy load (`/notes` 접근 시에만 로드)

### 10.7 접근성
- 영문 지문에 적절한 `lang="en"` 속성
- 한국어 텍스트에 `lang="ko"` 속성
- TTS 버튼에 명확한 aria-label
- 키보드 네비게이션 지원 (어휘 카드 좌우 화살표)
